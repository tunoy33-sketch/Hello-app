# Retrospectiva - Hello App

## ¿Qué funcionó bien?
El proyecto "Hello App" fue fácil de entender porque tenía instrucciones claras y user stories definidas desde el inicio. El proceso de crear el repositorio en GitHub fue sencillo siguiendo los pasos de la guía, y el diagrama de flujo ayudó a visualizar el funcionamiento de la aplicación antes de escribir código. Además, poder trabajar a mi propio ritmo me permitió revisar cada paso con calma.

## ¿Qué no funcionó / qué me costó trabajo?
Al ejecutar el código localmente, tuve problemas con el nombre del archivo y la ubicación, lo que me causó confusión al principio. Tener que aprender a usar GitHub, Git y draw.io al mismo tiempo fue un desafío porque eran herramientas completamente nuevas para mí. También, como no tengo experiencia previa con programación en Python, entender el código y adaptarlo tomó más tiempo del que esperaba.

## ¿Qué haría distinto la próxima vez?
Guardaría los archivos con el nombre correcto desde el principio para evitar errores al ejecutarlos. Practicaría más los comandos básicos de Git antes de empezar el proyecto para sentirme más seguro. También revisaría toda la documentación del proyecto antes de comenzar a programar y pediría ayuda más temprano si me atoro en algún paso, en lugar de intentar resolverlo solo por mucho tiempo.
