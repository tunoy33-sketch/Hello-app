# Hello App

## Descripción
Aplicación que saluda al usuario en su idioma nativo utilizando su ubicación (geolocalización) y un servicio de traducción.

## User Stories (Historias de Usuario)
- Como usuario, quiero ver un panel de login con campos para usuario y contraseña.
- Como usuario, quiero escribir mi nombre de usuario y contraseña (la contraseña debe verse con asteriscos).
- Como usuario, quiero hacer clic en "Login" para iniciar sesión.
- Como usuario, quiero ver un mensaje de error si dejo algún campo vacío (el borde se pone rojo).
- Como usuario, quiero ver un mensaje de bienvenida en mi idioma nativo al iniciar sesión.
- Como usuario, quiero hacer clic en "Logout" para cerrar sesión.
- Como usuario, quiero ver un mensaje de despedida al cerrar sesión.

## Justificación de la elección del proyecto

Elegí desarrollar el proyecto **Hello App** porque es adecuado para el nivel de experiencia requerido y cuenta con un alcance pequeño y definido. La aplicación permite trabajar con diferentes conceptos del desarrollo de software sin requerir una implementación excesivamente compleja.

El proyecto consiste en crear una aplicación que utilice la ubicación del usuario para mostrar un saludo en su idioma nativo. Esto permite abordar una necesidad de personalización de la experiencia del usuario, adaptando el mensaje mostrado de acuerdo con su ubicación.

Además, considero que este proyecto es apropiado para la práctica porque permite aplicar los conceptos estudiados en la Unidad 1 de Fundamentos de Ingeniería de Software, incluyendo la identificación de requisitos mediante historias de usuario, la planeación, el modelado, la construcción y el cierre del proyecto.

Por estas razones, elegí **Hello App** como mini-proyecto, ya que su alcance permite aplicar y documentar las diferentes fases del proceso de desarrollo de software utilizando GitHub como herramienta de apoyo.

## Metodología

### Metodología elegida: Ágil - Kanban

Para el desarrollo del proyecto elegí una **metodología ágil utilizando Kanban**, debido a que el proyecto tiene un alcance pequeño y sus funcionalidades pueden dividirse fácilmente en tareas independientes.

El uso de Kanban permite organizar las historias de usuario en diferentes actividades y visualizar el estado de cada una mediante un tablero. De esta manera, es posible identificar qué tareas están pendientes, cuáles se encuentran en desarrollo y cuáles han sido completadas.

Esta metodología resulta adecuada para el desarrollo individual del proyecto porque permite mantener una organización clara de las actividades y llevar un seguimiento del progreso durante el tiempo disponible para realizar la práctica. También facilita establecer prioridades y trabajar de manera incremental en las diferentes funcionalidades de la aplicación.

Además, GitHub Projects permite utilizar un tablero Kanban y GitHub Issues permite registrar y dar seguimiento a las tareas derivadas de las historias de usuario. De esta forma, GitHub se utiliza como herramienta CASE para apoyar la planeación, organización y seguimiento del proyecto.

Por lo tanto, elegí una metodología ágil con Kanban porque se adapta al tamaño y alcance del proyecto y permite mantener un control visual y ordenado de las actividades durante su desarrollo.
